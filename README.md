# Barbershop Bot

Телеграм бот для записи в барбершоп.

## Переменные окружения (Railway)

| Переменная | Описание | Пример |
|---|---|---|
| BOT_TOKEN | Токен бота от @BotFather | 123456:ABC... |
| ADMIN_ID | Твой Telegram ID | 830297830 |
| PHONE_NUMBER | Телефон барбершопа | +7 (999) 123-45-67 |
| BARBERSHOP_NAME | Название | Мой Барбершоп |
